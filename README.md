# 年度排休規劃表

一個單檔網頁工具，用來規劃每年的排休：預排各月的特休、年假，自動加總、檢查每月休假上限，並追蹤跨年度的特休週期。開啟即用，不需安裝、不需網路連線。

**線上使用：** https://sharonliao66.github.io/leave-planner/年度排休規劃表.html

---

## 功能

- **逐月排休**：例假固定 7 天、國定假日天數與說明可自行編輯，特休、年假直接輸入，右側即時顯示每月合計。
- **上限檢查**：每月休假合計超過上限（預設 15 天，含特休、例假、年假）時，數字會變紅並提示超出天數。
- **年假期限**：年假須於 3 月底前休完，因此 4 月之後的月份不顯示年假欄位。
- **特休週期追蹤**：以「重置日到下個重置日」為一個週期（例如 10/5）。可輸入上期特休總額與去年已休天數，工具會算出「剩餘未休」，還沒休完會紅字提醒，避免特休作廢。
- **多年度切換**：標題左右的 ◀ ▶ 可切換年度，已內建 2026、2027，可繼續往後新增，各年資料獨立儲存。
- **配色主題**：內建米白綠、藍、暖橘、粉紫、純白、深色六種主題，點色點即可切換。
- **備份與列印**：可將所有年度匯出成 JSON 備份、再匯入還原；也能直接列印或存成 PDF。
- **手機適用**：窄螢幕下自動調整排版。

---

## 使用方式

1. 開啟上方的線上網址（手機請用 Safari 或 Chrome，不要用「檔案」App 直接開）。
2. 在設定區調整每月上限、年假總額、特休重置日、上期特休總額與去年已休天數。
3. 逐月填入特休、年假；需要時修改國定假日的天數與說明。
4. 上方統計卡與提醒區會即時更新，超上限或特休未休完都會提示。

## 資料儲存說明

資料存在**瀏覽器本機**（localStorage），因此：

- 同一支裝置、同一個瀏覽器會自動記住，下次打開資料還在。
- **不會跨裝置或跨瀏覽器同步**——手機與電腦是各自獨立的兩份資料。
- 要把資料從一台裝置搬到另一台，請用「匯出備份」存成 JSON，再到另一台「匯入備份」。
- 清除瀏覽器資料或使用無痕模式可能導致資料無法儲存；建議定期匯出備份留底。

## 更新網頁
